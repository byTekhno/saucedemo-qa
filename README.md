Учебный проект ручного тестирования сайта [saucedemo.com](https://www.saucedemo.com) — демо-магазина от Sauce Labs.

Цель репозитория — показать, как я прогоняю проверки, фиксирую результаты и оформляю дефекты. Автоматизация будет отдельным этапом.

## Учётные данные демо-сайта

Пароль для всех пользователей: `secret_sauce`

| Логин | Зачем нужен в тестах |
|---|---|
| `standard_user` | Основной позитивный сценарий |
| `locked_out_user` | Негатив: заблокированный пользователь |
| `problem_user` | Известные функциональные баги |
| `performance_glitch_user` | Медленный отклик |
| `error_user` | Ошибки в действиях с товарами и чекаутом |
| `visual_user` | Визуальные дефекты вёрстки |
