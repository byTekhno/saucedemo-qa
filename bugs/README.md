# Баг-репорты

Сюда кладём дефекты, которые **сами воспроизвели**.

Примеры `BUG-001` … `BUG-003` — известные демо-проблемы ролей `problem_user` и `visual_user`. Их нужно **подтвердить руками**, вставить дату прогона и скрин. Если поведение изменилось — обнови отчёт, не оставляй чужую правду.

Шаблон нового бага: [TEMPLATE.md](TEMPLATE.md)

Правила:

1. Один файл — один дефект
2. В заголовке: что сломано и где
3. Всегда пиши логин, браузер, URL
4. Не заводи баг на `locked_out_user`, если он просто не пускает в систему с текстом ошибки
5. Если баг только у одной роли — так и напиши: «не воспроизводится на standard_user»

## Домашнее задание

После смоука заведи **минимум 3 своих** репорта. Ищи здесь:

- чекаут с пустой корзиной
- кнопка Back после Logout
- сортировка и картинки у `problem_user`
- поля формы у `error_user` / `problem_user`
- вёрстка у `visual_user` на узком экране
- налог и округление, если возьмёшь несколько товаров
