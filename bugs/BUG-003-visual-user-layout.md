# BUG-003 Сломанная вёрстка у visual_user (каталог, корзина, мобильная ширина)

**Статус:** Confirmed  
**Серьёзность:** Major  
**Приоритет:** Medium  
**Окружение:** Windows 11, Chrome 139, ~1920×1080 и ширина ~375px  
**Пользователь:** `visual_user` / `secret_sauce`  
**Дата обнаружения:** 2026-08-20  
**Дата подтверждения:** 2026-08-22

## Шаги

1. Войти как `visual_user` / `secret_sauce`
2. Открыть каталог `/inventory.html`
3. Добавить товары, открыть корзину `/cart.html`
4. Сравнить выравнивание кнопок и карточек с `standard_user`
5. Повторить каталог при узкой ширине окна (~375px)

## Фактический результат

Вёрстка сломана на нескольких экранах:

- Каталог (desktop): кнопка `Remove` у части товаров (например Test.allTheThings() T-Shirt) съезжает за пределы карточки
- Корзина: кнопки `Remove` уезжают вправо, между ценой и кнопкой большой пустой зазор
- Мобильная ширина: логотип/корзина в шапке смещены, между описанием товара и ценой/кнопкой огромные вертикальные отступы

Покупка в целом возможна, но UI выглядит неисправным, элементы визуально «ломают» карточки.

## Ожидаемый результат

Карточки выровнены, кнопки внутри своих блоков, на мобильной ширине без больших пустот и смещений — как у `standard_user`.

## Дополнительно

- Воспроизводится всегда на `visual_user`
- На `standard_user` не воспроизводится
- Это заложенный дефект демо-роли; с точки зрения роли пользователя — баг
- Скрин: `bugs/screenshots/BUG-003-inventory.png` — каталог, съехавшая кнопка
- Скрин: `bugs/screenshots/BUG-003-cart.png` — корзина, кнопки Remove уехали вправо
- Скрин: `bugs/screenshots/BUG-003-mobile.png` — узкая ширина, разъехавшаяся вёрстка

## Примечание

Серьёзность Major (не Critical): сценарий покупки не заблокирован полностью, но UI заметно сломан на desktop и mobile.
