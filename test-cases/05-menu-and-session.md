# Тест-кейсы: меню и сессия

**Модуль:** Navigation / session  
**Пользователь:** `standard_user`

| ID | Название | Приоритет |
|---|---|---|
| TC-NAV-001 | Logout возвращает на логин | P0 |
| TC-NAV-002 | После Logout нельзя открыть каталог по Back | P0 |
| TC-NAV-003 | Прямой URL каталога без логина | P0 |
| TC-NAV-004 | Reset App State очищает корзину | P1 |
| TC-NAV-005 | All Items из карточки товара | P2 |
| TC-NAV-006 | About открывает сайт Sauce Labs | P2 |

---

## TC-NAV-001 Logout

**Приоритет:** P0  
**Предусловие:** пользователь в каталоге.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть бургер-меню | Пункты: All Items, About, Logout, Reset App State |
| 2 | Нажать Logout | Страница логина. Поля пустые |

---

## TC-NAV-002 Кнопка «Назад» после выхода

**Приоритет:** P0  
**Предусловие:** выполнен вход, затем Logout.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Нажать Back в браузере | Каталог не показывается в рабочем состоянии. Либо логин, либо редирект на логин. Нельзя продолжить покупку без нового входа |

---

## TC-NAV-003 Закладка внутренней страницы

**Приоритет:** P0  
**Предусловие:** пользователь не авторизован. Сессия чистая (инкогнито или после Logout).

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | В адресной строке открыть `https://www.saucedemo.com/inventory.html` | Редирект на логин. Каталог недоступен |
| 2 | Повторить для `/cart.html` и `/checkout-step-one.html` | То же: без сессии внутренние страницы закрыты |

---

## TC-NAV-004 Reset App State

**Приоритет:** P1  
**Предусловие:** в корзине 2 товара.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Меню → Reset App State | Бейдж исчез. В каталоге снова Add to cart |
| 2 | Открыть корзину | Список пустой |

---

## TC-NAV-005 All Items

**Приоритет:** P2  
**Предусловие:** открыта карточка любого товара.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Меню → All Items | Переход на `/inventory.html` |

---

## TC-NAV-006 About

**Приоритет:** P2

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Меню → About | Открывается сайт Sauce Labs (внешний URL). Приложение магазина при этом не «падает» |
