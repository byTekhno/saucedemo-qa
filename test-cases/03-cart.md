# Тест-кейсы: корзина

**Модуль:** Cart  
**URL:** `/cart.html`  
**Пользователь:** `standard_user`


| ID          | Название                                | Приоритет |
| ----------- | --------------------------------------- | --------- |
| TC-CART-001 | Пустая корзина                          | P1        |
| TC-CART-002 | Continue Shopping возвращает в каталог  | P1        |
| TC-CART-003 | Remove удаляет товар и обновляет бейдж  | P0        |
| TC-CART-004 | Несколько разных товаров сохраняют цены | P0        |
| TC-CART-005 | Checkout из корзины с товарами          | P0        |
| TC-CART-006 | Checkout из пустой корзины              | P1        |


---

## TC-CART-001 Пустая корзина

**Приоритет:** P1  
**Предусловие:** вход выполнен, корзина пустая.


| Шаг | Действие        | Ожидаемый результат                                                                                  |
| --- | --------------- | ---------------------------------------------------------------------------------------------------- |
| 1   | Открыть корзину | Заголовок Your Cart. Список позиций пустой. Бейджа нет или он равен 0. Кнопка Continue Shopping есть |


---



## TC-CART-002 Continue Shopping

**Приоритет:** P1  
**Предусловие:** в корзине 1 товар (Backpack).


| Шаг | Действие                 | Ожидаемый результат                                               |
| --- | ------------------------ | ----------------------------------------------------------------- |
| 1   | Нажать Continue Shopping | Переход на `/inventory.html`. Бейдж = 1. У Backpack кнопка Remove |


---



## TC-CART-003 Удаление из корзины

**Приоритет:** P0  
**Предусловие:** в корзине Backpack и Bike Light, бейдж = 2.


| Шаг | Действие                 | Ожидаемый результат                                 |
| --- | ------------------------ | --------------------------------------------------- |
| 1   | Нажать Remove у Backpack | В корзине остался только Bike Light. Бейдж = 1      |
| 2   | Перейти в каталог        | У Backpack снова Add to cart, у Bike Light — Remove |


---



## TC-CART-004 Несколько товаров

**Приоритет:** P0  
**Предусловие:** корзина пустая.


| Шаг | Действие                                    | Ожидаемый результат                              |
| --- | ------------------------------------------- | ------------------------------------------------ |
| 1   | Добавить Backpack ($29.99) и Onesie ($7.99) | Бейдж = 2                                        |
| 2   | Открыть корзину                             | Обе позиции, цены совпадают с каталогом, QTY = 1 |


На этом сайте нельзя увеличить количество одного SKU кнопкой «+». Если получится добавить Backpack дважды как две строки — зафиксировать фактическое поведение.

---



## TC-CART-005 Переход к чекауту

**Приоритет:** P0  
**Предусловие:** в корзине хотя бы 1 товар.


| Шаг | Действие        | Ожидаемый результат                                                               |
| --- | --------------- | --------------------------------------------------------------------------------- |
| 1   | Нажать Checkout | Открывается `/checkout-step-one.html` с полями First Name, Last Name, Postal Code |


---



## TC-CART-006 Чекаут из пустой корзины

**Приоритет:** P1  
**Предусловие:** корзина пустая.


| Шаг | Действие                          | Ожидаемый результат                                                                                                                                             |
| --- | --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Открыть корзину и нажать Checkout | Либо переход на форму с последующим осмысленным запретом пустого заказа, либо Checkout недоступен. Пустой заказ не должен успешно завершиться на Thank you page |


Фактическое поведение сайта нужно зафиксировать при прогоне: это частый спорный момент демо.
